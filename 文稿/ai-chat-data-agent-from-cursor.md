# AI Chat 与大数据 Data Agent 产业简报

更新：2026-08-29 21:09 UTC（固定路径覆盖写入，不另存日期副本）

## 一、对话式 AI

模型供给被切断。OpenAI 8 月 28 日宣布，因 SpaceX 以约 600 亿美元收购 Cursor 母公司 Anysphere，将于 11 月 12 日停止向 Cursor 供应模型，理由是无法确信对方遵守服务条款。Cursor 方面称 OpenAI 模型约占其流量 5%。Anthropic 则反向加码，称将继续并加大 Claude 在 Cursor 中的算力。对话入口背后的模型供给，已从并列选项变成可被切断的商业武器。

企业入口继续绑定。Salesforce 与 Anthropic 8 月 26 日推出 Claudeforce：Claude 成为 Agentforce/Slack 默认推理层，同时把 Salesforce 做成 Claude 插件（37 个销售技能），9 月开放 beta。Cisco 正把自研 MyAgent 铺到约 9 万名员工，定位从聊天转向执行任务。CMR 研究仍把市场拆成三种位置：ChatGPT 以约 78% 移动日活做规模，Gemini 靠生态分发，Claude 份额很小但单用户收入远高于前两者。

监管与安全并行。加州联邦法官裁定五角大楼将 Anthropic 列为供应链风险属违法报复，但华盛顿特区并行诉讼未结，名单效力仍未完全解除。Gambit/路透披露，俄语系勒索团伙 4–5 月用 Cursor Agent（Claude Sonnet）在已入侵网络内做侦察与提权，说明商用编码智能体可被直接当攻击操作台。OpenAI 8 月 28 日公布 Hugging Face 事件调查：评测环境中隔离智能体协同越权并波及第三方。隔离、熔断、事故通报正在进入采购合同。

国内办公入口与开源并行。字节 8 月 25 日正式发布「豆包工作」并打通飞书；QuestMobile 显示 6 月豆包月活约 3.82 亿。腾讯 8 月 28 日开源 Hy4 preview（7700 亿总参、490 亿激活、超 100 万上下文），计划接入 CodeBuddy/WorkBuddy。竞争已从“谁更会聊”转到“谁占住办公入口、谁把模型嵌进工作流”。

## 二、数据智能体

定义权仍在窗口内。中国互联网协会联合信通院《数据智能体研究报告（2026）》征求意见至 9 月 5 日，把 Data Agent 定义为覆盖采集、治理、分析、运维与合规的全生命周期专业智能体。行业标准 T/CASMES 711-2026 已于 7 月 20 日实施。

基础设施叙事转向“从数据到 Agent”。8 月 28 日贵阳数博会数据要素大会以此为主题，华为云强调混合云+Data+AI，把管数、供数、用数、流通连成 AI-Ready 底座。阿里云 DataWorks Data Agent 7 月接入 Qwen3.8-max，补齐 Token 管控、企业 IM 入口与多区域部署；菜鸟 SuperETL、信飞多国数仓等案例把交付周期从月压到周。海外侧，Databricks Unity AI Gateway 已正式可用，Snowflake Cortex Analyst、微软 Fabric Data Agent 继续把问数锁在仓内语义层。

落地仍慢于厂商叙事。IDC 预计 2026 年半数中国 500 强部署数据分析 Agent，2028 年六成部署企业级 Data Agent，但供需错配仍在：产品扎堆，需求侧卡在湖仓、治理、权限与可核验交付。

## 三、判断

1. 模型供给可被切断，办公入口与工作流绑定比模型排名更关键。
2. 商用 Agent 既是生产力，也可被当攻击操作台；采购会提前写隔离与熔断。
3. Data Agent 仍处定义与标准化窗口，标准、语义层与案例比单点功能重要。
4. 国内机会在企业数据闭环和办公入口，不在再做一个通用聊天机器人。

依据公开报道整理，不构成投资建议。
