## 大数据 Data Agent

IDC《MarketScape：中国 Data Agent 2026》18 家入选、仅 4 家领导者，阿里云居最前；预测 2028 年 60% 中国 500 强将部署企业级 Data Agent。DataWorks 覆盖开发、治理、分析、运维。数博会后北电数智发布面向 Agent 全场景的可信数据空间。Databricks 9 月 2 日让 AI Search 支持 struct/map 与仅过滤查询，Git Folder Serverless 进 Beta，并把 3.8 Flash / Fable 5.1 收进托管；Genie One 联网搜索进 Beta，可引用外部文档。Microsoft Fabric Data Agent 可直接挂镜像库做 NL2SQL。Snowflake Horizon Context 把指标定义下沉数据层，Cortex Coding Agent 已 GA。Gartner 警告超 40% 的 Agent 项目或于 2027 年前失败。竞争从参数比拼转向语义层、网关与对结果负责。

## 判断

对话入口继续比更便宜的长程 Agent。本小时新事实：3.8 Flash 应用量再增约 9 亿 token，日窗口 Prompt 再抬约 48 亿，缓存把实付输入价压到标价约三成，Vertex 份额微降、命中微升，Flex 可用性继续修复但延迟仍高一个数量级。监管与诉讼无新增量。数据栈一边收新模型，一边让 Agent 能联网核对外部文档。
