# AI Chat 与大数据 Data Agent 产业简报

更新：2026-11-10 04:11Z

## 一、对话式 AI

市场：Graphite/Similarweb（Forbes 11/9）称 ChatGPT 9 月全球会话份额 81.2%、美国 80.7%，周活约 12 亿，6 月低点后回升约 0.8 个百分点。Claude 会话同比约 +1901% 至 54 亿，Gemini 约 +182% 至 37 亿，二者仍未破 10%。StatCounter 10 月网页份额：全球 ChatGPT 51.58%、Gemini 28.86%、Perplexity 15.04%；美国 ChatGPT 37.10% 对 Gemini 35.42%，近乎并列。11 月至今转介口径有媒体把 Gemini 排第一，样本未满月且与会话量尺子冲突，不宜单表定胜负。国内 QuestMobile：9 月 AI 原生产品月活约 5.46 亿，豆包约 4.19 亿、千问约 1.58 亿、DeepSeek 约 1.23 亿；终端系统级 AI 用户约 7.8 亿，AI 办公月活约 1.42 亿。

产品与厂商：OpenAI 11/9 把 ChatGPT Enterprise（Chat、Work、Codex、dots）上架 AWS Marketplace，可走 AWS 账单与承诺额度，Healthcare/FS 亦可；市集工作区可选存储地区，但推理驻留目前仅美国。dots 管理预览至 11/18。微软 Copilot 连接器写操作（增删改）已在 Chat/Cowork GA，默认需用户确认，Researcher 仍只读。国内同日：千问办公 2.0 升为 Team Agent；腾讯元器停服，数据导出受理至 2027/1/9，办公入口收束到 WorkBuddy（9 月月活约 3235 万）。豆包工作 SuperCLUE 办公测评 85.33 居首。字节 Seedream 5.5 上线即梦/豆包/方舟：百轮编辑、原生 RGBA，2K 编辑约 0.28 元（较 5.0 Pro 约便宜 60%、快 40%）。美团 LongCat-2.5 开源（1.6 万亿总参、约 480 亿激活、百万上下文、MIT）。蚂蚁灵光 2.0 用户破 2000 万，首周管理超 116 万项事务、接 40+ 官方 API。荣耀联合中移动推智能体服务网络与 Magic9 Token 套餐；豆包手机助手 155 款 App 拒绝屏幕代操作。阿里云 Token Plan 个人版额度约 +74%–78%。

## 二、数据智能体

湖仓争的是“业务上下文谁说了算”。Databricks 11/9 把 Genie Ontology、Genie Slack/Teams 标为 GA：Ontology 合成 Unity Catalog 语义与用量所学知识，经 Genie One MCP 对外；旧 Beta 端点 11/30 停用。同日新增：MDM 可全局预置 Claude desktop（仅 macOS）；Slack/Teams 里 Genie 外联工具需审批（公开预览）；Power BI 语义可作外部知识源（Beta）。Snowflake 把 Business Ontology、Cortex AI Gateway、Bots 继承员工权限、CoCo Cloud Agents 绑在一起。Google Knowledge Catalog 扩展语义模型已 GA（LookML、dbt、Snowflake Semantic Views、Databricks Metric Views、SAP CSN），Gemini Data Cloud 连接器预览按用户身份查数。共性：没有语义层的自然语言查仓不安全。

## 三、治理与判断

1. 对话入口从“谁更聪明”转到“谁占住办公/终端第一触点”；开源长程 Agent 模型与官方 API 闭环并行，乌镇互联公约与 155 个“不”并存。
2. 数据 Agent 胜负手是 Ontology + 权限 + 审计，而非模型参数。
3. 治理窗口：网信办 11/9 上线新技术新应用备案系统（生成式 AI/算法/深度合成一体）；Claude 文本水印 Amazon Bedrock 滚动至 11/10 完成；《欧盟 AI 法案》第 50(2) 条机读标记过渡至 12/2；欧盟拟 2027–28 学年给 15 岁学生发 AI 素养证书。
