## 二、数据智能体

仓内 Agent 从只读问答改成可写回的数字劳动力。Snowflake Cortex Coding Agent 已商用；CoCo automations 公测可定时无人值守跑数。Databricks Unity AI Gateway 已商用；Genie Code 已做成 Lakeflow Jobs 任务（Beta）。本小时增量：Databricks 托管 MCP（Genie One / Genie Code）已并入 Unity AI Gateway（Beta），对话取数与编码进入同一治理面。Fabric Data Agent 在 Foundry 改走 MCP。Google 推出 Gemini Enterprise for Legal。Oracle 把自然语言查数做到 Database Console。Dataiku Agent Management 预计 9 月上线。IDC 称 2028 年六成中国 500 强将部署企业级 Data Agent。

国内：腾讯云 DataBuddy 讲 SemQL 语义层。2026 被称 Agent「应用元年」，评价转向任务交付与 Token 消耗。华为云推「从 Data 到 Agent」。阿里 DataWorks Data Agent 接入 Qwen3.8-max。数博会发布贵阳壹号词元工厂，海光首发 Agent to Token 架构。高质量数据集超 12.6 万个、1815PB。国家数研院拟组词元出海联合体。互联网协会与信通院《数据智能体研究报告（2026）》征求意见截至 9 月 5 日，还剩 5 天。
