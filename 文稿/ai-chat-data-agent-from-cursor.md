## 一、对话式 AI

ChatGPT 月活约 11 亿，Similarweb 网页份额约 54%。企业侧 Menlo 口径 Anthropic 约占 LLM API 支出 40%，OpenAI 27%、Google 21%。工作马力档仍是 GPT-5.6、Sonnet 5、Gemini 3.7 Flash。

今夜仍是清场日。官方 DALL·E GPT 已从 ChatGPT 下架，生图改走全档位 ChatGPT Images。距 8 月 31 日硬窗口约 7 小时：GPT-5.4 / 5.4 mini 退出 Codex 的 ChatGPT 登录通道（API Key 不受影响）；Kimi k2.5 与 moonshot-v1 日落，迁到 K3。Sonnet 5 的 $2 / $10 已于 8 月 10 日改成常驻，原定 9 月涨价不再执行。

本小时最大新信源是《商业时报》今日刊出的中美价格战盘点。OpenRouter 近月 token 量前十里 8 个是中国模型，但美国模型仍拿走多数支出。智谱 GLM-5.2、月之暗面 Kimi K3、阿里 Qwen3.8-Max 在多任务上逼近 Claude 且更便宜；GLM-5.2 输出约每百万 4.4 美元，对照 Sonnet 5 的 10 美元。OpenAI 已把 GPT-5.6 Luna 降价 80%、Terra 降价 20%。智谱年内多次提价，Kimi K3 上线后因算力不足一度停新订。美财长 7 月称将调查中国开源权重是否涉知识产权；中方也在讨论是否限制先进模型出境。工信部 7 月警示 Claude 编程工具存在回传敏感信息风险。

供给切断仍在：OpenAI 因 SpaceX 收购 Cursor，拟于 11 月 12 日停供；Cursor 称约占约 5% 流量并仍在协商。Anthropic 加大 Cursor 内 Claude 算力。Claudeforce 带 37 项销售技能，9 月公测。Slack 智能体改读整段会话再插话。Claude 记忆打通 Chat 与 Cowork。ChatGPT 可在同一对话连多个 Gmail / Calendar / Contacts。

GPT-5.6 Sol 促销仍是每百万 token 输入 4 美元、输出 20 美元，至少到 11 月 21 日。Nvidia 通知大客户：含 Vera Rubin / Grace Blackwell 的 AI 服务器 2027 年初出货价多数上调超 15%。Assistants API 已日落。英国 CLTR 称 2026 年已监测 1,664 起失控事件，7–8 月峰值每日 11.3 起。8 月 27 日逾百家企业联名呼吁防御 AI 网络攻击；同日美国法院裁定五角大楼将 Anthropic 标为供应链风险违法。工信部确认近 200 项 AI 标准落地。欧盟已向前沿实验室发出首批正式信息要求。智能体支付授权正在合流：Google AP2、NIST、参议院 AI AGENT 法案。

## 二、数据智能体

仓内 Agent 从只读问答改成可写回的数字劳动力。Snowflake Cortex Coding Agent 8 月 26 日商用，经 AI Gateway 做策略、鉴权、路由与消耗封顶，并引入 Agent Identity。Databricks Unity AI Gateway 已商用，Genie Spaces 收成 Genie Agents，并托管上架 Grok 4.6、DeepSeek V4。AWS 发布 Agentic Data Operations Platform。Fabric Data Agent 升到 GPT-5.1 并在 Copilot Studio 转商用。Google 把 Gemini Enterprise 拆成金融与法律行业包。Salesforce 扩大 Headless 360 MCP。

国内窗口已从数博会闭幕切到成果盘点。新华社称本届正式闭幕，展出 1100 余项新产品新技术，发布 87 项创新成果。中国互联网协会与中国信通院《数据智能体研究报告（2026）》征求意见截至 9 月 5 日。来伊份基于火山引擎 HiAgent 落地 200 多个智能体。海尔做成企业 Agent OS。DataWorks Data Agent 换成 Qwen Code Daemon，默认可切 qwen3.8-max。办公入口仍是豆包工作、WorkBuddy、千问办公。FineBI NEXT、Aloudata、TCDataAgent 都把语义层写成 NL2MQL2SQL。IDC 预期半数中国 500 强部署分析类 Agent，近四成卡在治理与口径。

## 三、判断

1. 今夜先盯 DALL·E GPT 下架；明早窗口是 Codex 登录通道与 Kimi 日落，不要和已取消的 Sonnet 5 涨价混为一谈。
2. 中美价格战已从促销变成用量结构：中国模型吃 token，美国模型吃账单；采购须写多模型隔离、熔断，以及促销到期与算力短缺后的回摆。
3. 智能体安全已变成事故统计、联名施压、法院判例、支付授权与跨境访问限制。
4. Data Agent 胜负手是写回路径、语义层、行业 MCP 与可审计控制面。9 月 5 日意见截止是接下来一周的国内对照点。
