# AI Chat 与大数据 Data Agent 产业简报

更新：2026-09-23 18:11 UTC（固定路径覆盖写入，不另存日期副本）

## 一、对话式 AI

本小时增量：OpenAI 把最强语音 GPT-Live 接到 ChatGPT 网页与移动端，可用说话委派多步、跨应用、需浏览器的任务；产品负责人演示分析外卖账单、订场、改日程，称逾 1.5 亿人已用听写或语音。官方帮助中心同步划线：Chat 语音已上桌面/网页/iOS/Android；Work/Codex 语音主入口仍是桌面，网页与移动无独立 Work 语音，仅支持配对 iOS 远程。此举对准 Instinct、Meta Muse 等个人助手，并为 2027 智能音箱铺路；DevDay 在下周。财政部长 Bessent 与何立峰再谈“未竟事项”，窗口压在特朗普与习近平明日（9/24）华盛顿会晤前；议题含国家级 AI 事故通报热线，芯片与蒸馏仍是卡点，市场不预期大协议。Bessent 仍被报领跑新设“AI 沙皇”，未任命。

产品价效比未变：Grok 4.7 以每百万 Token 2/6 美元进 Cursor 与 API，尚未进 Azure Foundry / AWS Bedrock。Claude Opus 5.5 为 4/20（缓存读 0.20）。GPT-6 Sol（2/10）与 Luna（0.10/0.50）腰斩且为长期价，上线 Work、Codex 与 API，常规 Chat 仍无 Sol/Luna。Sol 在 AutomationBench xhigh 为 33.2%、单任务约 0.27 美元。Comscore Q2：1–6 月提示份额 ChatGPT 70%→50%、Gemini 17%→30%、Claude 2%→11%。国内分层未破：豆包日常，DeepSeek 推理与低价 API，千问办公，Kimi 长上下文与 Agent。马克龙在联大呼吁打造不依附美中的开源前沿模型。

## 二、数据智能体

Data Agent 从问数转向“受治理地连仓、出看板、可观测、可语音指挥”。OpenAI 9/10 在 ChatGPT Work 上线 Data agent，对接 Snowflake、BigQuery、Databricks、Redshift 等，写入 dbt / Horizon / Genie 语义层，可在 Tableau、Power BI 等出看板并继承行列权限；本小时语音上移动，使问数与委派可在通勤中完成。Databricks 称 Genie One MCP 已 GA。Snowflake 9/22 宣布 Observe 的 Agent Observability 即将私测。腾讯云 DataBuddy 以 Unity Semantics、Agent Runtime、OneOps 三层覆盖工程/治理/分析/科学，已在中国、泰国、韩国、印尼上线。Teradata 把 Tera 升级为跨平台 coworker，并嵌入 WisdomAI；Context Engine 与 Harness 计划 2026 Q4。Google Cloud 9/9 预览 Data Agent Kit。

国内：快手 9/19 披露周活超 10600、周人均对话 55。云栖上阿里把 OpenLake 推向 Agentic Lake；DataWorks Context Graph 称业务问答准确率 93.24%。IDC《中国 Data Agent 2026》18 家入围、4 家进领导者，阿里云居首。

## 三、判断

1. 对话入口从打字扩到语音：谁先把语音接到可执行 Agent，谁占移动场景。
2. 任务单价决定路由，旗舰只留最难任务。
3. Data Agent 胜负手仍是治理过的上下文、MCP 分发与可观测。
4. 安全已上峰会议程，但约束力弱于芯片、出口与投资审查。
5. 国内机会在企业数据闭环与云厂商全栈，不在再做一个通用聊天框。
