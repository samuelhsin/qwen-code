## AI 对话

## 大数据 Data Agent

IDC《MarketScape：中国 Data Agent 2026》18 家入选、仅 4 家领导者，阿里云居最前。DataWorks Data Agent 覆盖开发、治理、分析、运维四类智能体，AIDBS 对接 100 余种多模多云源，数据可不搬迁建 Agent。IDC 预测 2028 年 60% 中国 500 强将部署企业级 Data Agent。古茗自助分析从天级压到 2–4 小时，菜鸟 SuperETL Skill 研发效率称提升 10 倍。

海外侧，Snowflake Cortex Sense 与 Databricks Genie Ontology 都在给自家 Agent 喂治理过的业务语义，但两边都不核对最终数字对不对。Genie One / Agents 免费期延至 2027-01-31。国内竞争已从参数比拼转向：能否接 ERP、处理非结构化数据、对业务结果负责；MCP 成为企业 Data Agent 对接系统的基础门槛。

## 判断

对话入口在比更便宜的长程 Agent，数据栈在比语义层加可验收闭环。本小时新事实是：3.8 的独立评测与电脑操控短板已见诸媒体，用量日桶尚未滚到发布日；Data Agent 选型被 IDC 图谱与语义层缺口同时拉紧。
