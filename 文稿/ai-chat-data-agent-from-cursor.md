## 二、数据智能体

Data Agent 从问数转向“受治理地连仓、出看板、可观测”。Databricks 称 Genie One MCP 已对全部用户 GA，经 Unity Gateway 把本体与权限交给外部智能体。Snowflake 9/22 宣布 Observe 的 Agent Observability 即将私测，10/22 办发布会；Cortex Agents 已进 Teams 与 M365 Copilot。Fabric data agent 可发 Copilot Agent Store，并可直接接镜像库（含 Snowflake、Databricks）做 NL2SQL。腾讯云 9/22 正式发布 DataBuddy，覆盖工程/治理/分析/科学四场景，语义层准确率 95.9%（对照 NL2SQL 83.5%），称效率 5–10 倍，已在中国、泰国、韩国、印尼上线。OpenAI 9/10 在 ChatGPT Work 上线 Data agent；Google Cloud 9/9 预览 Data Agent Kit。

国内：快手 9/19 披露周活超 10600、周人均对话 55、单任务提效中位 13 倍。云栖上阿里把 OpenLake 推向 Agentic Lake；DataWorks Context Graph 称业务问答准确率 93.24%。IDC《中国 Data Agent 2026》18 家入围、4 家进领导者，阿里云居首。语义层、权限与审计比单点 Text-to-SQL 更决定成交。

## 三、判断

1. 对话模型进入价效比阶段：谁把旗舰能力压到可规模化的任务单价，谁锁住 Agent 负载。
2. Chat 变成工作入口；界面绑定数据连接、语义层和权限。
3. Data Agent 胜负手是治理过的上下文加 MCP 分发与可观测，不是再做一个聊天框。
4. 安全与治理已升到安理会议程，但约束力仍弱于芯片与出口管制。
5. 应用层已按任务单价换模型；国内机会在企业数据闭环与云厂商全栈。
