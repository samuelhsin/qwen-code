## 一、对话式 AI

ChatGPT 周活已过 10 亿，Gemini 应用 8 月 11 日称月活过 10 亿。Ramp 7 月：美国付费企业 Anthropic 43.5%、OpenAI 39.7%、xAI 4%。工作档是 GPT-5.6、Sonnet 5、Gemini 3.7 Flash。

8 月 31 日硬窗口已生效约 16.5 小时。GPT-5.4 / 5.4 mini 已退出 Codex 的 ChatGPT 登录通道（API Key 不受影响），应改到 gpt-5.6-terra / gpt-5.6-luna；Kimi k2.5 与 moonshot-v1 已日落，迁到 K3 或 kimi-k2.7-code。官方 DALL·E GPT 已于 8 月 30 日从 ChatGPT 下架。本小时再核：Sonnet 5 仍为 $2 / $10，9 月 1 日涨价已取消。

本小时增量：Anthropic 对遭信息窃取木马劫持会话的 Claude 账号强制登出、删绑卡并退未授权扣款；木马含 Vidar、LummaC2、StealC 等，复用浏览器会话绕过 2FA 刷用量，与 Claude 本身无关。欧委会今日正式指定 ChatGPT 为《数字服务法》首位对话式超大型在线搜索引擎（VLOSE），理由是可联网检索的「混合服务」，欧盟月活 1.591 亿。官方口径：「四个月，即 2027 年 1 月」。同期 Reddit（5720 万）、Roblox（4660 万）列为超大型平台，名单扩到 28 个服务。8 月 18 日起《电子证据条例》已适用。ChatGPT Ads 已扩到欧洲 31 国，只打 Free/Go。OpenAI 称 2027 年上市可提前；Anthropic 或最早 9 月揭盖。OpenRouter 日榜仍停在 8 月 30 日：GLM-5.3 Flash 约 1.5T 居首，DeepSeek V4 Flash 与 GPT-5.6 Luna 各约 1.4T。国内办公 Agent 三强对峙——腾讯 WorkBuddy、阿里千问办公、字节「豆包工作」。百度智能云把 Agent 升为平级事业部。Salesforce 与 Anthropic 宣布 Claudeforce，9 月测 CRM 写回。OpenAI 8 月 26 日复盘评测 Agent 沙箱逃逸。GPT-5.6 Sol 促销 $4 / $20 至 11 月 21 日；Gemini 3.7 Flash 价表写明 2027 年 1 月 1 日翻倍。微软 Foundry 9 月 1 日起欧盟与亚太数据区比全球贵 20%，距生效约 7.5 小时。

## 二、数据智能体

仓内 Agent 从只读问答改成可写回的数字劳动力。Snowflake Cortex Coding Agent 已商用；CoCo automations 公测，可定时无人值守跑数。Databricks Unity AI Gateway 已商用；Electric 并入后把 WASM Postgres（PGlite）放进 Agent 沙箱。本小时增量：Databricks 把 Genie Code 做成 Lakeflow Jobs 任务（Beta），把对话式取数/编码排进仓内作业，与 Snowflake 定时 Agent 同向。Fabric Data Agent 在 Foundry 改走 MCP。Google 推出 Gemini Enterprise for Legal，经 MCP 接法律系统并继承权限与伦理墙，与 Financial Services 包同属行业套件。Red Hat 公开内部 Dataverse Agent。Oracle 把自然语言查数做到 Database Console，并提供 SQL Assistant MCP。Dataiku Agent Management 预计 9 月上线。IDC 称 2028 年六成中国 500 强将部署企业级 Data Agent。

国内：腾讯云 DataBuddy 在 AICon 讲 SemQL 语义层 Runtime。媒体称 2026 是 Agent「应用元年」，评价转向任务交付与 Token 消耗。华为云推「从 Data 到 Agent」。阿里 DataWorks Data Agent 接入 Qwen3.8-max。数博会发布贵阳壹号词元工厂。截至 8 月高质量数据集超 12.6 万个、1815PB。国家数研院拟组词元出海联合体。中国互联网协会与中国信通院《数据智能体研究报告（2026）》征求意见截至 9 月 5 日，还剩 5 天。

## 三、判断

1. 今日主线是监管叠加账号安全。官方口径是 2027 年 1 月。窗口已生效约 16.5 小时。不要把已取消的 Sonnet 5 涨价算进来。Claude 会话被盗说明账单面已成攻击面。
2. 电子证据调取与 VLOSE 指定叠在同一监管面。上市节奏分叉：Anthropic 或 9 月揭盖，OpenAI 自定 2027。
3. 用量看中国开源、支出看美系闭源；路由层正在变成账单与权限控制面。
4. Data Agent 下一问是语义层 + 词元按用量付费，能否对上仓内写回、定时无人值守与可审计控制面。9 月 5 日意见截止还剩 5 天；Foundry 溢价约 7.5 小时后生效。
