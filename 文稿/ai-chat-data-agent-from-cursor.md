# AI Chat 与大数据 Data Agent 产业简报

更新：2026-11-10 05:10Z

## 一、对话式 AI

市场：Graphite/Similarweb（Forbes 11/9）称 ChatGPT 9 月全球会话份额 81.2%、美国 80.7%，周活约 12 亿；6 月低点后回升约 0.8 个百分点。Claude 会话同比约 +1901% 至 54 亿，Gemini 约 +182% 至 37 亿，二者仍未破 10%。StatCounter 10 月网页份额：全球 ChatGPT 51.58%、Gemini 28.86%、Perplexity 15.04%；美国 ChatGPT 37.10% 对 Gemini 35.42%。11 月至今快报把 Gemini 排到约 55.8%、ChatGPT 约 5.4%，属未满月转介/页面口径，与会话量尺子冲突，不宜单表定胜负。国内 QuestMobile：9 月 AI 原生 App 去重月活约 5.46 亿，豆包约 4.19 亿、千问约 1.58 亿、DeepSeek 约 1.23 亿、元宝约 3733 万；豆包人均 72 次/132.5 分钟，DeepSeek 人均时长 136.7 分钟居首。规模与变现脱节：豆包 C 端日收入仍约百万元量级，火山引擎 MaaS 上半年约 48 亿元、公有云份额约 45.1%。

产品与厂商：OpenAI 11/4 推 Images 2.6（约快 50%、可出 GIF，图带 SynthID+C2PA）；11/9 把 ChatGPT Enterprise（Chat、Work、Codex、dots）上架 AWS Marketplace，可走 AWS 账单，推理驻留目前仅美国，dots 管理预览至 11/18。Anthropic 在美对 Pro/Max/Ultra 开 Personal Finance 只读 beta（Plaid 连账）。Google Gemini Omni 1.2 Flash 已 GA，原生视频最长约 15 秒。微软 Copilot 连接器写操作在 Chat/Cowork GA，默认需确认。国内：千问办公 2.0 升 Team Agent（协作空间、自动任务、人机共创），可绑 Token Plan。腾讯元器 11/9 停服，数据导出受理至 2027/1/9，办公入口收束到 WorkBuddy（9 月约 3235 万月活，办公 Agent 第一；百度搭子约 977 万、千问办公约 790 万）。字节 Seedream 5.5、美团 LongCat-2.5（MIT 开源）仍在铺开；蚂蚁灵光 2.0 用户破 2000 万；豆包手机助手遭约 155 款 App 拒绝屏幕代操作。

## 二、数据智能体

湖仓争的是“业务上下文谁说了算”。Databricks 11/9 把 Genie Ontology、Genie Search、Genie Slack/Teams 标 GA：Ontology 合成 Unity Catalog 语义与用量所学知识，经已 GA 的 Genie One MCP 对外；旧 Beta MCP 端点 11/30 停用。同日：MDM 可全局预置 Claude desktop（仅 macOS）；Slack/Teams 外联工具需审批（公开预览）；Power BI 语义可作外部知识源（Beta）。Snowflake Expedition（11/3）把 Business Ontology、Cortex AI Gateway（推理/可观测/成本管理已 GA）、CoCo Cloud Agents 绑在一起，Bots 继承员工权限。Google Knowledge Catalog 扩展语义模型已 GA（LookML、dbt、Snowflake Semantic Views、Databricks Metric Views、SAP CSN），内部基准称 grounding 后准确率约 4 倍、Token 最多少约 75%。共性：没有语义层和权限继承的自然语言查仓不安全。

## 三、治理与判断

1. 对话入口从“谁更聪明”转到“谁占住办公/终端第一触点”；会话份额、网页份额、转介份额三把尺子互相打架。
2. 数据 Agent 胜负手是 Ontology + 权限 + 审计，而非模型参数。
3. 治理窗口：网信办 11/9 上线新技术新应用备案系统（生成式 AI/算法/深度合成/区块链一体）；Claude 文本水印 Amazon Bedrock 滚动至 11/10 完成；《欧盟 AI 法案》第 50(2) 条机读标记过渡至 12/2。
