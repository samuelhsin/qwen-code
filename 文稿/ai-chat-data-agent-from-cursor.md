## 一、对话式 AI

本小时增量：媒体把今日 ChatGPT Voice 升级拆成三件事——语音可挂 GPT-6 Astra/Sol/Luna；邮件、日历、Slack 等插件接通语音；Voice 接到网页与移动端的 ChatGPT Work。TechCrunch 称 Plus/Pro 可在手机 Work 页写文档、拟邮件、摘要 Slack，Free/Go 可用插件；语音与文字可来回切，通勤会话可回桌面续。官方帮助中心仍划线：Work/Codex 独立语音主入口是桌面，Codex 网页与移动不可选，仅 iOS Remote 配对。产品负责人演示用说话分析外卖、订场、改日程，称逾 1.5 亿人已用听写或语音；对标 Instinct、Meta Muse，并为 2027 智能音箱铺路。Anthropic 已合并 Cowork 与 Chat，OpenAI 仍拆 Chat / Work / Codex。DevDay 9/29 旧金山，Altman 主题演讲 10:00。Bessent 与何立峰今日再谈“未竟事项”，窗口压在特朗普与习近平明日华盛顿会晤前；议题含国家级 AI 事故热线，芯片与蒸馏仍是卡点，市场不预期大协议。

价效比未变：Grok 4.7 为 2/6 美元进 Cursor 与 API。Opus 5.5 为 4/20（缓存读 0.20）。GPT-6 Sol（2/10）与 Luna（0.10/0.50）腰斩且为长期价，上线 Work、Codex 与 API，常规 Chat 仍无 Sol/Luna。Comscore Q2：1–6 月提示份额 ChatGPT 70%→50%、Gemini 17%→30%、Claude 2%→11%。国内分层未破：豆包日常，DeepSeek 推理与低价 API，千问办公，Kimi 长上下文与 Agent。

## 二、数据智能体

Data Agent 从问数转向“受治理地连仓、出看板、可观测、可语音指挥”。OpenAI 9/10 在 Work 上线 Data agent，对接 Snowflake、BigQuery、Databricks、Redshift 等，写入 dbt / Horizon / Genie 语义层，可在 Tableau、Power BI 出看板并继承行列权限；今日语音上移动，使问数可在通勤中完成。Snowflake 9/22 把 Opus 5.5 当日放进 Cortex 的 CoCo、CoWork、Cortex Agents，调用不出治理边界；Observe 的 Agent Observability 即将私测。Databricks 称 Genie One MCP 已 GA。腾讯云 DataBuddy 以 Unity Semantics、Agent Runtime、OneOps 三层覆盖工程/治理/分析，已在中国、泰国、韩国、印尼上线。Google Cloud 9/9 预览 Data Agent Kit。

国内：快手 9/19 披露周活超 10600、周人均对话 55。云栖上阿里把 OpenLake 推向 Agentic Lake；DataWorks Context Graph 称业务问答准确率 93.24%、SQL 一致性 99%。IDC《中国 Data Agent 2026》18 家入围、4 家进领导者，阿里云居首。

## 三、判断

1. 语音已接到可执行 Work，不只是听写；谁先打通插件与治理数据，谁占移动场景。
2. 任务单价决定路由，旗舰只留最难任务。
3. Data Agent 胜负手仍是语义层、MCP 分发与仓内治理，不是再做一个聊天框。
4. 峰会热线约束力弱于芯片、出口与投资审查。
5. 国内机会在企业数据闭环与云厂商全栈。
