## 一、对话式 AI

市场：Similarweb 10 月网站访问 ChatGPT 55.7%、Gemini 24.2%、Claude 11.5%（+1.9pp），不含 App。Graphite（含 App）9 月会话 760 亿、同比 +37%，ChatGPT 占 81.2%、周活 12 亿，86% 在 App；外链 60/14/10。StatCounter 10 月相对 9 月有方法断裂，勿环比。爱分析 10 月：豆包工作月活 5500 万；千问办公 4748 万；WorkBuddy 提及度 36.0% 居首。

产品：Wallet 先给美国 ChatGPT Pro、满 18、美发卡：dots 代付，逐笔 Face ID/指纹，卡组织发代币，卡号不进 agent/商家；合作 Amex、Mastercard、Visa。Businesses in ChatGPT（11/10 测试）Hub 认领资料；美国电商可发 Business Agent，成交仍回网站。12/11 退役 Advanced/Standard Voice，GPT-Live 承接几乎全部语音。Anthropic 推 Claude Meetings（先接 Google Meet）、Whiteboards 与 Sheets 测试；连接器点名 Adobe、Atlassian、Box、Notion、HubSpot。Dashboards 改名 Claude Data 并 GA，企业计划 11/20 默认打开。拟议 IPO：8.25 亿股、70–78 美元、代号 ANT，拟 11/18 定价、11/19 上市；Class N 私募 26 亿美元；前三季营收 332.42 亿美元，十月末年化约 810 亿美元。Google Carbon 引入价 $2/$10、11/30 后 $4/$20 并下发 Ultra；Hydrogen $1.50/$7.50。Jules 已只读、12/31 关停。美国预览 Gemini for healthcare，点名 HCA、Highmark、Northwell、Optum。满 18 个人账号 Gems 11/17 只读并迁 skills、12/17 删除；Opal 同日关。国内：千问办公 2.0 于 11/9 上线 Team Agent；元器 11/9 停服、导出至 2027/1/9；扣子企业版 11/30 停新售（非整站停售）。

## 二、数据智能体

湖仓争控制面、语义层与渠道。Claude Data 可接 Redshift、BigQuery、ClickHouse、Databricks、Snowflake 与 Salesforce，认证查询仍测试。Databricks 11/9 将 Genie Ontology、Genie Search、Slack/Teams 标 GA；11/11 Pages GA，Genie One Windows 桌面端进 Beta。Genie 插件现可嵌 ChatGPT、Claude、Copilot Cowork、Grok Bot。常开版走 Unity Catalog/Gateway。ZeroOps 盯作业。旧 Beta MCP 11/30 停须迁 Unity Gateway。Snowflake 把 Ontology、AI Gateway、CoCo 绑在权限审计上，CoCo 进 Excel/Sheets（预览）。阿里云 SLS 以语义层问日志。数据宝 One Agent 双轨只读。共性：没有语义层和权限继承的自然语言查仓不安全。

## 三、治理与判断

1. 对话入口从「回答」扩到「代付」：Wallet 仍逐笔生物识别；商家 Agent 抢入口，成交仍回网站。
2. 数据 Agent 胜负手是 Ontology + 权限 + 审计 + 渠道；办公 Agent 升到会议/白板/表/群。
3. 窗口：网信办 11/9 上线 beian.cac.gov.cn。欧盟 AI 法案 50(2) 过渡至 12/2。Copilot Studio 11/12 已停 GPT-4.1 / Mini 与 GPT-5 Chat / Auto / Reasoning（标准迁 GPT Chat Latest，套件迁 GPT-6 Luna / 6.1 Sol；限制跨区与 FedRAMP 可不随下线；标准套件可开 30 日延用；EU/EFTA 禁跨区 GPT-5 Chat 可留至 11/30）。GitHub Copilot 11/16 下线 Claude Opus 4.8/5 与 GPT-5.6 Terra（个人年付仍可留 Opus 4.8）。Gems 11/17 只读；Claude Data 企业默认 11/20；Genie MCP Beta 与 Carbon 引入价叠在 11/30。旧语音 12/11 退役。
