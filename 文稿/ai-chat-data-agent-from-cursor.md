# AI Chat 与大数据 Data Agent 产业简报

更新：2026-11-10 22:09Z

## 一、对话式 AI

市场：Similarweb（11/10）10 月网站访问 ChatGPT 55.7%（9 月 56.4%）、Gemini 24.2%（25.0%）、Claude 11.5%（9.6%，+1.9pp）。Graphite（含 App）9 月六大助手会话 760 亿、同比 +37%，ChatGPT 占 81.2%、周活约 12 亿，86% 会话在 App；外链 ChatGPT 60%、Gemini 14%、Claude 10%。StatCounter 10 月页面浏览 ChatGPT 51.58%、Gemini 28.86%（外链口径，且对 9 月有断点）。爱分析 10 月：豆包工作月活 5500 万，千问办公 4748 万，WorkBuddy 提及度 36%。

产品与厂商：OpenAI 11/10 上线 Businesses in ChatGPT（测试）：Business Hub 认领/核验资料与货盘，给聚合洞察（提及、点击，不回传对话）；合格美国电商与在线服务可发 Business Agent，对话独立标注，可作 Ads 落地；政策禁止未经批准功能代交表单/预订/下单，现只解释产品政策并链回官网。Anthropic 同日推 Claude Meetings（Team/Enterprise 测试，先接 Google Meet，外宾入会即退）、Whiteboards 与 Sheets 测试，并试交互式连接器（Adobe/Atlassian/Box/Notion）；原 Dashboards 改名 Claude Data 并 GA；同日启动拟议 IPO 路演（Class A 8.25 亿股、70–78 美元、拟代号 ANT）。Google 11/10 向付费开发者/企业开放 Gemini 4 Carbon（长程智能体与网络安全，引入价 $2/$10，11/30 后 $4/$20），下发 Ultra 的 Gemini App、AI Mode 与 Antigravity（预览 /swarm）；美国预览 Gemini for healthcare（HIPAA，接 EHR/理赔，数据留在客户环境，首批 HCA、Highmark、Northwell）。国内：千问办公 2.0 于 11/9 上线 Team Agent（进钉钉群/文档/听记）；SuperCLUE-Office 10 月豆包工作 85.33、Kimi Work 84.57、WorkBuddy 83.99；元器 11/9 已停服、导出至 2027/1/9；扣子企业版 11/30 停新售。

## 二、数据智能体

湖仓争的是控制面、语义层与渠道。Claude Data 把仓/CRM 问数做成认证指标、数据故事与可分享看板，认证查询与实时分享仍测试。Databricks 11/9 把 Genie Ontology、Genie Search 以及 Slack/Teams 应用 GA；Genie One MCP 旧 Beta 端点 11/30 停须迁 Unity Gateway；11/10 宣布三年向荷兰投逾 5 亿美元，扩阿姆斯特丹研发、本地团队翻倍，并点名 Lakebase、Genie ZeroOps。Snowflake 把 Ontology、Cortex AI Gateway、CoCo Automations 绑在一起，让代理按用户权限跑定时巡检。阿里云 SLS 以语义层做自然语言查日志，并配 SessionStore 与官方 MCP Server。数据宝 One Agent 双轨只读问数。共性：没有语义层和权限继承的自然语言查仓不安全。

## 三、治理与判断

1. 含 App 时 ChatGPT 仍绝对领先，纯 Web 上 Claude 十月跳得最快；商家认领 + 商家 Agent 开始抢搜索与商家主页，但交易仍回网站。Anthropic 办公套件与 IPO 路演同日推进。
2. 数据 Agent 胜负手是 Ontology + 权限 + 审计 + 渠道分发；办公 Agent 从个人助手升到会议/白板/表/群。国内大厂收拢产品线，低代码智能体平台让位给主入口。
3. 窗口：网信办 11/9 上线备案系统（生成式 AI/算法/深度合成/区块链一体化）；欧盟 AI 法案 50(2) 对 8/2 前已上市系统的标记过渡至 12/2。Copilot Studio 11/12 停 GPT-4.1 / GPT-5 Chat；GitHub Copilot 11/16 下线 Claude Opus 4.8/5 与 GPT-5.6 Terra。Claude Data 企业版默认开启日为 11/19。
