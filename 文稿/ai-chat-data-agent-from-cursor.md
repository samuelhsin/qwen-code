## 大数据 Data Agent

IDC《MarketScape：中国 Data Agent 2026》18 家入选、仅 4 家领导者，阿里云居最前；预测 2028 年 60% 中国 500 强将部署企业级 Data Agent。落地难点在统一语义层与 Agent Ops；调研称 79% 企业已部署 Agent、仅 11% 跑通生产。Databricks 已让 Agent mode 覆盖全部 Genie Agents，并把 3.8 Flash / Fable 5.1 收进托管。Fabric Data Agent 可挂镜像库做 NL2SQL。Snowflake Cortex Coding Agent 已 GA。Gartner 警告超 40% 的 Agent 项目或于 2027 年前失败。腾讯 WorkBuddy 已适配银河麒麟、统信 UOS、鸿蒙。Boomi、Genesys 把发现、身份、策略与花费收进控制面；Navigator 预计 2026 财年 Q4 GA，Orchestrator 瞄准 2028 财年 Q1。竞争转向语义层、网关、控制面与对结果负责。
