## AI 对话

## 大数据 Data Agent

IDC《MarketScape：中国 Data Agent 2026》18 家入选、仅 4 家领导者，阿里云居最前；预测 2028 年 60% 中国 500 强将部署企业级 Data Agent。DataWorks 覆盖开发、治理、分析、运维。IDC 提示供需错配：厂商热情高于企业就绪度。落地难点在统一语义层与 Agent Ops。Databricks 已让 Agent mode 覆盖全部 Genie Agents，并把 3.8 Flash / Fable 5.1 收进托管；Unity Gateway 统一管模型、Agent、MCP 与预算。Microsoft Fabric Data Agent 可挂镜像库做 NL2SQL。Snowflake Horizon Context 把指标下沉数据层，Cortex Coding Agent 已 GA。Gartner 警告超 40% 的 Agent 项目或于 2027 年前失败。竞争从参数比拼转向语义层、网关与对结果负责。

## 判断

对话入口继续比更便宜的长程 Agent。本小时新事实：3.8 Flash 应用量仅再增约 2 亿 token，日窗口 Prompt 再抬约 97 亿；实付输入价压到 0.2172，Vertex 份额与命中再升；Flex 可用性微修、延迟再拉长，AI Studio Flex 失去最快档。监管与诉讼无本小时新增。数据栈一边收新模型，一边用网关管 Agent 对湖仓的多步取证。
