市场：Similarweb（11/10）10 月网站访问 ChatGPT 55.7%（9 月 56.4%）、Gemini 24.2%（25.0%）、Claude 11.5%（9.6%，+1.9pp）。Graphite（含 App）9 月会话 ChatGPT 81.2%、周活约 12 亿，86% 会话在 App。StatCounter 10 月页面浏览 ChatGPT 51.58%、Gemini 28.86%。爱分析 10 月中国 AI 办公：豆包工作月活 5500 万居首，千问办公 4748 万，WorkBuddy 提及度最高。

产品与厂商：本小时主线是办公套件化。Anthropic 11/10 推 Claude Meetings（Team/Enterprise 测试，先接 Google Meet，会中起草计划/白板/取数，外宾入会即退）、Whiteboards 与 Sheets 测试；原 Dashboards 改名 Claude Data 并 GA（认证查询与实时分享仍测试，Enterprise 11/19 默认开）；对话旁可打开 Adobe/Atlassian/HubSpot。Fable 5.2 / Mythos 5.2（11/9，$8/$40）进 Copilot GA、Bedrock Covered Model（需 `aws_review`）、Foundry。Copilot 合格企业 ZDR 至年底后转 EFS；Bedrock 合格客户 ZDR 至少至 2027/6/30。Google 11/10 向付费开发者/企业开放 Gemini 4 Carbon（长程智能体与网络安全，引入价 $2/$10，11/30 后 $4/$20），并美国预览 Gemini for healthcare（HIPAA 向，Epic/Oracle Health 只读）。OpenAI：Enterprise 上架 AWS Marketplace；dots 预览至 11/18，同一枚可连多台本机。国内：千问办公 2.0 Team Agent；SuperCLUE-Office 10 月豆包工作 85.33、Kimi Work 84.57、WorkBuddy 83.99；Kimi Hosted Agents；元器停服、导出至 2027/1/9；扣子企业版 11/30 停售、存量最晚 2027/12/31 下线；阿里云 Token Plan 个人额度约 +74–78%。

## 二、数据智能体

湖仓争的是控制面。Databricks 11/9 把 Genie Ontology / Search / Slack·Teams 标 GA，旧 Beta MCP 11/30 停，须迁 Unity Gateway；11/10 宣布三年向荷兰投逾 5 亿美元。Snowflake 把 Ontology、Cortex AI Gateway、CoCo Automations 绑在一起。Google Knowledge Catalog 语义 GA；Data Agent Kit GA。AWS AgentCore InvokeWebSearch 11/10 GA。Claude Data 把仓/CRM 问数做成认证指标与可分享看板。摩根大通把 Claude Code 从工程扩到风控与财富管理。共性：没有语义层和权限继承的自然语言查仓不安全。

## 三、治理与判断

1. 含 App 时 ChatGPT 仍绝对领先，纯 Web 上 Claude 最快；会议/白板/表/数成为下一触点，Marketplace/Bedrock/Foundry/Copilot 决定第一入口。
2. 数据 Agent 胜负手是 Ontology + 权限 + 审计 + 渠道分发；办公 Agent 从个人助手升到 Team Agent，并对 EHR/仓/会议动手。国内大厂收拢产品线，低代码智能体平台让位给主入口。
3. 窗口：网信办 11/9 上线备案系统；欧盟 AI 法案 50(2) 过渡至 12/2。MC1546438：Copilot 内 Claude 12 月初进 EU Data Boundary，12/9 未选择租户默认全员开通。Copilot Studio 11/12 停 GPT-4.1 / GPT-5 Chat；GitHub Copilot 11/16 下线 Opus 4.8/5 与 GPT-5.6 Terra。无许可证 Copilot Chat 限额收紧（MC1536158）。
