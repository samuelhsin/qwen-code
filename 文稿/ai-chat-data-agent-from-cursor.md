# AI Chat 与大数据 Data Agent 产业简报

更新：2026-11-11 00:12Z

本小时增量：Databricks Pages 标 GA；今日 9:00 PT DATA+AI LIVE 预告下一代 Genie；IPO 补 Class N 私募 260 亿美元与前三季营收/十月年化；Claude Data 仓接清单与 Help Center 今日更新。

## 一、对话式 AI

市场：Similarweb（11/10）10 月网站访问 ChatGPT 55.7%（9 月 56.4%）、Gemini 24.2%（25.0%）、Claude 11.5%（9.6%，+1.9pp），不含 App。Graphite（含 App）9 月六大助手会话 760 亿、同比 +37%，ChatGPT 占 81.2%、周活约 12 亿，86% 在 App；外链 60/14/10。StatCounter 10 月相对 9 月有方法断裂，不宜环比。爱分析 10 月（含聚合入口）：豆包工作月活 5500 万、提及度 33.3%；千问办公月活 4748 万；WorkBuddy 提及度 36.0% 居首。

产品与厂商：OpenAI 11/10 上线 Businesses in ChatGPT（测试）：Hub 认领资料与货盘、给聚合洞察且不回传对话；Help Center 今日更新，认领后须 Persona 核验；合格美国电商/在线服务可发 Business Agent，对话独立标注、可作 Ads 落地；现只解释政策并链回官网，不能代购、代订、查订单。Anthropic 同日推 Claude Meetings（Team/Enterprise 测试，先接 Google Meet，未授权时外宾入会即退）、Whiteboards 与 Sheets 测试；连接器原文点名 Adobe、Atlassian、Box、Notion、HubSpot；Dashboards 改名 Claude Data 并 GA，企业计划 11/19 默认打开。拟议 IPO：8.25 亿股、70–78 美元、代号 ANT，拟 11/18 定价、11/19 上市；Class N 私募 260 亿美元（AMD/博通/Google/美光/微软/英伟达/台积电）；前三季营收 332.4 亿美元（约 +1200%），十月末年化约 810 亿美元。Google 开放 Gemini 4 Carbon（引入价 $2/$10，11/30 后 $4/$20），下发 Ultra 与 Antigravity /swarm；预览 Gemini for healthcare，首批 HCA、Highmark、Northwell。国内：千问办公 2.0 于 11/9 上线 Team Agent（可关联钉钉群/文档/听记）；SuperCLUE-Office 10 月豆包工作 85.33、Kimi Work 84.57、WorkBuddy 83.99；元器 11/9 停服、导出至 2027/1/9；扣子企业版 11/30 停新售（非整站停售）。

## 二、数据智能体

湖仓争控制面、语义层与渠道。Claude Data 可接 Redshift、BigQuery、ClickHouse、Databricks、Snowflake 与 Salesforce，认证查询仍测试。Databricks 11/9 将 Genie Ontology、Genie Search、Slack/Teams 标 GA；11/11 Pages（按域治理的业务概念）GA；旧 Beta MCP 11/30 停须迁 Unity Gateway 的 `system.ai.genie_one_mcp`。11/10 宣布荷兰三年逾 5 亿美元，扩阿姆斯特丹研发、团队翻倍，点名 Lakebase、Genie ZeroOps。Snowflake 把 Business Ontology、Cortex AI Gateway、CoCo Automations 绑在权限与审计上。阿里云 SLS 以语义层问日志，并配 SessionStore 与官方 MCP。数据宝 One Agent 双轨只读。共性：没有语义层和权限继承的自然语言查仓不安全。

## 三、治理与判断

1. 含 App 时 ChatGPT 仍领先，纯 Web 上 Claude 十月跳得最快；商家 Agent 抢入口，成交仍回网站。
2. 数据 Agent 胜负手是 Ontology + 权限 + 审计 + 渠道；办公 Agent 升到会议/白板/表/群。国内低代码平台让位给主入口。
3. 窗口：网信办 11/9 上线 beian.cac.gov.cn。欧盟 AI 法案 50(2) 对 8/2 前已上市系统标记过渡至 12/2。Copilot Studio 11/12 停 GPT-4.1 / GPT-5 Chat（套件迁 GPT-6 Luna；GPT-6.1 Sol 已于 9/29 上市）；限制跨区流动的环境可不随此次下线。GitHub Copilot 11/16 下线 Claude Opus 4.8/5 与 GPT-5.6 Terra。Claude Data 企业默认 11/19；Genie MCP Beta 叠在 11/30。
