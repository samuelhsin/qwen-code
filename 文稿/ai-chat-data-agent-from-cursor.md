## 二、数据智能体

赛迪顾问：中国 Data Agent 2025 年 16.8 亿元，2026 上半年 18.3 亿元，全年预计 40.2 亿元；分析智能体占 35%、治理 24%。

湖仓争控制面。Databricks 11/16 发 AI Index（Unity Gateway 逾 1 万家）：开源权重 Token 占比 7 月至 11 月由 7.3% 升至 30.9%；单供应商企业由 64% 降至 28%；Opus 5.5 六周内占专有 Token 7.2%→37.9%；同成功率下 GPT-6 Luna 单任务约 $0.05、Opus 5.5 约 $1.62。Skills 指南仍把 Ontology（定义）与 Skills（方法）分开，经 Unity Gateway Skills（Beta）发布。Genie Ontology/Search 已 GA。Snowflake 把 Ontology、AI Gateway、CoCo Automations 绑在权限与审计上。共性：没有语义层和权限继承的自然语言查仓不安全。
