## 大数据 Data Agent

IDC《MarketScape：中国 Data Agent 2026》18 家入选、仅 4 家领导者，阿里云居最前；预测 2028 年 60% 中国 500 强将部署企业级 Data Agent。落地难点在统一语义层与 Agent Ops；调研称 79% 企业已部署 Agent、仅 11% 跑通生产。Databricks 已让 Agent mode 覆盖全部 Genie Agents，并把 3.8 Flash / Fable 5.1 收进托管。Fabric Data Agent 可挂镜像库做 NL2SQL。Snowflake Cortex Coding Agent 已 GA。Gartner 警告超 40% 的 Agent 项目或于 2027 年前失败。腾讯 WorkBuddy 已适配银河麒麟、统信 UOS、鸿蒙。竞争从参数比拼转向语义层、网关与对结果负责。

## 判断

对话入口继续比更便宜的长程 Agent。本小时：Prompt 从 583 亿跳到 673 亿，应用量再增约 12 亿 token；输入价回升到 0.225、输出到 4.196；Vertex 份额再升，Flex 延迟回落，AI Studio 成最快。天猫把 Token 订阅读进电商充值；EFS 把企业对话的日志主权还给客户云。数据栈一边收新模型，一边用网关管湖仓取证。
