# AI Chat 与大数据 Data Agent 产业简报

更新：2026-08-30 02:09 UTC（固定路径覆盖写入，不另存日期副本）

## 一、对话式 AI

聊天入口仍高度集中，但领先幅度继续收窄。Similarweb 5–6 月口径显示，ChatGPT 约占全球聊天机器人网页流量 54%，较一年前的 77%–87% 明显回落；Gemini 同期近五倍增长，Claude 流量最小但在与 OpenAI 的企业头对头中约赢七成。OpenAI 称 ChatGPT 约 10 亿周活。8 月 6 日起免费与 Go 档默认 GPT-5.6 Luna、文本对话不限次，并加 Think 按钮做加深推理；Plus/Pro 用 GPT-5.6 Sol 与思考滑杆。谷歌 8 月 13 日上线面向编码与智能体的 Gemini 3.7 Flash，导入价每百万 token 0.75/3.75 美元（至年底），并接入 Spark 与 Gemini Enterprise Agent Platform。Anthropic 已在 6–7 月连发 Claude 5 系（Fable/Sonnet/Opus）。

产品形态继续从“会聊”转向“代办+自带浏览器+能付款”。独立浏览器 Atlas 已于 8 月 9 日关停，浏览智能体并入 ChatGPT 桌面端、Work 与 Chrome 插件。Visa、Mastercard、Rain、Circle、Fiserv 等组建 Agentic Payments Alliance，试图统一智能体身份与授权；Linux 基金会运营的 x402 支付标准已落地，新加坡金管局 7 月发布 SAFR，要求智能体决策与执行之间必须过授权关。供给侧政治化未消退：OpenAI 拟因 SpaceX 收购 Cursor 于 11 月停供模型，英国失控观测与“紧急关断”修正案、五角大楼与 Anthropic 的供应链诉讼仍在发酵。

## 二、数据智能体

仓内 Agent 正在变成平台标配。Snowflake 8 月 26 日让 Cortex Agents Coding Agent 正式商用：托管沙箱可跑 bash、读写文件、检索、SQL 与 Skills，应用侧不必自建循环；此前 8 月 20 日预览了 Python 代码执行。Databricks 把原 Genie Spaces 收成 Genie Agents，Agent 模式可多步假设检验、连跑 SQL 并出带引用的报告。两边都把准确率押在语义层/指标与权限治理上，出仓即掉点。

国内叙事从图谱转向交付与基础设施。8 月 28 日贵阳数博会以“从数据到 Agent”开场，华为云抛出混合云+Data+AI 的 AI-Ready 全链路（管数、供数、用数、可信流通），称大模型与智能体已成为新的数据消费者。21 世纪经济报道 8 月下旬专访称 2026 是 Agent 应用元年：评价标准从功能清单改成任务完成率与 Token 账本。工程侧共识是 L2 条件自动化——NL2SQL 加上语义模型、Multi-Agent 与 Skill，关键步骤留人审；Shopee 在 QCon 复盘称纸面 Text-to-SQL 九成准确率落到复杂 OLAP 可跌至一成。IDC 仍预期 2026 年半数中国 500 强部署分析类 Agent，但近四成项目卡在治理与口径不清。

## 三、判断

1. 流量战让位于办公入口、自带浏览器、行业包与智能体支付协议。
2. 模型供给与跨境合规可被政治切断，采购须写隔离、熔断与事故披露。
3. Data Agent 胜负手是语义层、权限审计与可核验交付，不是再做一个聊天框。
4. 国内窗口在岗位级数字员工与湖仓到 Agent 的闭环，不在通用对话产品。

依据公开报道整理，不构成投资建议。
