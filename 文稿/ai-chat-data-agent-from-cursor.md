## 三、治理与判断

1. 支付/短信/邮件/电话/CRM 写回都做成「先确认再执行」；湖仓侧数据不出域、代码封装、审计共享。Entra 给本地 Agent 发 Agent ID；Autopilot 自带 Agent ID 与具名管理员。Agent 365 加 FinOps（Cost Management 预览、Business Analytics Frontier）。
