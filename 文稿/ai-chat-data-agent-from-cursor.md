## 三、判断

1. 网页/移动 Work 语音已落地；剩下的是 Codex 本地闭环与口头审批。Gemini 用连接应用补对话入口，并用 TTS 抢语音代理。
2. 任务单价决定路由，旗舰只留最难任务。
3. Data Agent 胜负手是语义层、MCP 与仓内治理，不是再做一个聊天框。
4. 热线与晚宴是姿态，约束力弱于芯片、出口与投资审查；深圳会前难落地。
5. 国内机会在企业数据闭环与云厂商全栈。
