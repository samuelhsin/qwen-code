## 二、数据智能体

Snowflake Expedition 把「Agent 上生产」押在三件套：Business Ontology（权威指标）、Cortex AI Gateway（模型/工具/MCP 策略）、CoCo/CoWork Bots（后台长驻、按用户权限执行）。Deloitte 口径仅 11% 组织把 Agent 放进生产（38% 仍试点）。OpenAI ChatGPT Work Data agent 与 Claude 仪表盘同时抢仓库直连和语义层；Databricks 走 Unity AI Gateway + Genie/Agent Bricks。Tessell 推 Gemini 库管/治理/迁移三 Agent。跨平台审计仍是缺口。

## 三、治理与判断

1. 入口收敛：国内砍重复 Agent 平台、资源砸主入口；海外对话产品默认打开个人 Agent，IT 须在 11/18 前定 dots 权限。
2. 数据侧胜负手是语义层、按 Agent 身份授权、花费封顶与可审计，不是模型参数。
3. 监管收口：欧盟 AI 法执法程序征求意见今日截止，AI Office 已查 OpenAI/Anthropic；Claude 文本水印对接第 50 条，Bedrock 至 11/10。乌镇二十家（含华为、腾讯、阿里、抖音）签智能体安全公约。英国 ICO 对 Agent 取证至 11/20。欧法院法务官意见：聊天机器人复述新闻有版权风险。
