## 二、数据智能体

湖仓争控制面、语义层与渠道。Claude Data 可接 Redshift、BigQuery、ClickHouse、Databricks、Snowflake 与 Salesforce，认证查询仍测试。Databricks 11/9 将 Genie Ontology、Genie Search、Slack/Teams 标 GA；今日 Pages GA（认证/弃用、MANAGE PAGES、REST），Genie One Windows 桌面端同日进 Beta。入站可放行 ChatGPT/Claude 的 Genie MCP 插件。旧 Beta MCP 11/30 停须迁 Unity Gateway。Metric Views 可发 Power BI（私有预览；DirectQuery）。11/10 宣布荷兰三年逾 5 亿美元，点名 Lakebase、Genie ZeroOps。今日 9:00 PT DATA+AI LIVE 预告下一代 Genie。Snowflake 把 Ontology、AI Gateway、CoCo Automations 绑在权限与审计上，并把 CoCo 送进 Excel/Sheets（预览）。阿里云 SLS 以语义层问日志。数据宝 One Agent 双轨只读。共性：没有语义层和权限继承的自然语言查仓不安全。

## 三、治理与判断

1. 含 App 时 ChatGPT 仍领先，纯 Web 上 Claude 十月跳得最快；商家 Agent 抢入口，成交仍回网站。
2. 数据 Agent 胜负手是 Ontology + 权限 + 审计 + 渠道；办公 Agent 升到会议/白板/表/群。
3. 窗口：网信办 11/9 上线 beian.cac.gov.cn。欧盟 AI 法案 50(2) 过渡至 12/2。Copilot Studio 11/12 停 GPT-4.1 / Mini 与 GPT-5 Chat / Auto / Reasoning（标准迁 GPT Chat Latest，套件迁 GPT-6 Luna / 6.1 Sol；限制跨区与 FedRAMP 可不随下线；标准套件可开 30 日延用；EU/EFTA 禁跨区 GPT-5 Chat 可留至 11/30）。GitHub Copilot 11/16 下线 Claude Opus 4.8/5 与 GPT-5.6 Terra（个人年付仍可留 Opus 4.8）。Claude Data 企业默认 11/19；Genie MCP Beta 与 Carbon 引入价叠在 11/30。旧语音 12/11 退役。
