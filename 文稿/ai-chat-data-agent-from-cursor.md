## 二、数据智能体

赛迪顾问：中国 Data Agent 2025 年 16.8 亿元，2026 上半年 18.3 亿元，全年预计 40.2 亿元；分析智能体占 35%、治理 24%。属存量数据软件的 AI 增强增量。

湖仓争控制面。Databricks 11/16 指南把 Ontology（定义）与 Skills（方法）分开：技能用 Agent Skills 格式，经 Unity Gateway Skills（Beta）发布为 Unity Catalog 对象，可供 MCP Agent 复用。Genie Ontology/Search 已 GA；always-on 仍非 GA；Slack 应用已 GA。11/13 与 OpenAI：ChatGPT+Genie 插件、Codex 走 Unity Gateway、GPT 在 Model Serving。共性：没有语义层和权限继承的自然语言查仓不安全。

## 三、治理与判断

1. 含 App 时 ChatGPT 仍领先，纯 Web 上 Claude 十月跳得最快；商家 Agent 抢入口，成交仍回网站。
