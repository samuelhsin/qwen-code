# AI Chat 与大数据 Data Agent 产业简报

更新：2026-11-06 17:15Z

## 一、对话式 AI

对话产品本周继续从问答转向账户上下文、影像与个人办事。

OpenAI 11/3 称 ChatGPT 触发的网页搜索量约等于 Google 搜索量的 20%（The Verge；口径由 OpenAI 自定）。11/4 Images 2.6 上线 ChatGPT／Codex／API：生成约快 50%，支持 GIF；官方称全平台每周约 40 亿张图。11/5 GPT-6 Cyber 仅向经核验的 Daybreak Red 客户开放，系统卡评为网络安全 Critical，用于授权渗透与漏洞研究。美国 Free／Go 仍在图像生成旁试投放视觉广告。

Anthropic 11/5 在美国 Pro／Max／Ultra 推 Personal Finance Beta：经 Plaid 只读接入银行／卡／贷款／投资账户，最多约 24 个月流水；不能转账或投顾，无广告。同日为企业档加安全中心与推理钩子。METR 评估称 Anthropic 在明确任务上的能力增速约为 2025 年 10 月前的两倍，但证据大量脱敏。

Google Gemini Omni 1.2 Flash（11/5）视频 3–15 秒、多轮修改，720p 约 $0.07/秒，较 1.1 降价约 30%。Meta Muse 在美国上线语音与表情形象。百度发布 ERNIE 5.5 Flash Base（2800 亿总参、140 亿激活）预训练权重。Cloudflare 为站点增加个人智能体流量允许／拦截策略。

国内焦点是 Personal Agent 与办公付费。蚂蚁灵光 2.0 称一周管理超 116 万项事务、累计用户超 2000 万；千问 Go 嵌在千问 App 做多步事务；字节 Spell 项目据报将并入豆包。11/4 乌镇峰会 20 家企业签《智能体发展自律公约》，但约 155 款 App 仍拒绝豆包屏幕自动化。双11 把 Token 做成零售：千问办公 0.01 元月卡半小时约售 10 万份、对应约 2 万亿 Token。QuestMobile：9 月豆包月人均使用 72.0 次、DeepSeek 65.9 次；AI 办公月活约 1.42 亿，WorkBuddy 约 3235 万、千问办公约 791 万。

## 二、数据智能体

湖仓把 Data Agent 从问数推到修管道、管口径、控花费。Snowflake Expedition（11/3）发布 CoCo Cloud Agents／Automations：云端隔离容器跑定时巡检与管道修复，工程师审批后才上线；Interactive Analytics 给人与 Agent 亚秒查询。Cortex AI Gateway、Sandboxes、Guardrails 把身份、MCP 调用和提示注入防护收到数据所在处；Business Ontology／Cortex Sense 要把“营收”等口径做成可审批的权威定义。官方称流式吞吐最高约 20GB/s、P50 就绪约 3 秒（内部测于 10/20）。Deloitte 2026：38% 试点 Agent，仅 11% 进入生产。

Databricks 以 Agent Bricks、Unity Gateway、Omnigent 强调选择、上下文与管控，避免 Agent 蔓延。其 2026 State of AI Agents 称多 Agent 系统使用四个月增 327%；Neon 遥测显示由 Agent 创建的数据库两年内从 0.1% 升至约 80%。

阿里云 ADA（约 11/3）以 Ada 主智能体调度 MaxCompute／Hologres／Flink／EMR／DataWorks 等引擎 Agent，强调语义图谱与对话即交付。DataWorks Data Agent 覆盖集成—开发—运维—治理—分析，并推自主巡检。竞争壁垒从模型参数转向企业口径、权限审计和 Credit 限额。

## 三、判断

1. 对话入口在抢搜索份额、账户上下文和语音／影像，同时用广告与 Token 零售试探付费。
2. 个人智能体的瓶颈是授权与互操作：用户可授权，平台仍可拒绝屏幕代操。
3. Data Agent 胜负手是治理：语义一致、身份继承、沙箱、可观测与花费上限。没有这些，试点很难变成生产。
