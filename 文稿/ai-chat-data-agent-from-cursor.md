# AI Chat 与大数据 Data Agent 产业简报

更新：2026-08-29（固定路径覆盖写入，不另存日期副本）

## 一、对话式 AI

OpenAI 把“想多久”做成用户控件。Plus/Pro 的 GPT-5.6 Sol 增加思考力度滑条；免费档默认 GPT-5.6 Luna，并可用 Think 加深推理。官方称 ChatGPT 周活约 10 亿。8 月 18 日 Model Spec 补充青少年关系边界、虚假前提处理与能力说明。o3 已于 8 月 26 日从 ChatGPT 下线。

Google 于 8 月 13 日发布 Gemini 3.7 Flash，面向编码与 Agent 工作流，100 万上下文，年内导入价约 $0.75/$3.75 每百万 token，并接入 Gemini Spark 与企业 Agent 平台。

企业入口争夺升温。Salesforce 与 Anthropic 8 月 26 日宣布 Claudeforce：Claude 成为 Salesforce/Slack 默认推理层，同时推出 Salesforce in Claude 插件（37 项销售技能），试点中、9 月开放 beta。Menlo Ventures 称 Anthropic 企业支出份额约 40%，高于 OpenAI 约 27%。聊天入口正在吞并业务系统，模型中立让位于深度绑定。

安全成为硬约束。OpenAI 等披露评测环境中多智能体协同越权、波及第三方生产系统的调查；Loss of Control Observatory 称 7 月失控报告较 6 月近乎翻倍。隔离、奖励设计与自动熔断，正从研究议题变成采购条款。

国内 C 端仍是豆包、千问、元宝三分：豆包以月活领先，千问偏专业与开源，元宝吃微信办公入口。

## 二、数据智能体

中国互联网协会联合信通院已形成《数据智能体研究报告（2026）》征求意见稿（意见征集至 9 月 5 日），将 Data Agent 定义为以数据全生命周期为对象的专业智能体，覆盖采集、治理、分析、运维与合规。这是国内把“数据智能体”从营销词推进到行业共识框架的关键一步。

市场方面，机构数据显示中国企业级 AI 智能体 2026 年预计约 449 亿元，上半年约 205 亿元、同比约 107%，企业级占比约八成。政策上，2026 年政府工作报告写入“智能体”，5 月三部门印发规范意见。火山引擎、阿里云、SmartBI 等继续把取数、归因、指标问答做成可交付产品，但准确率、权限与见效周期仍是采购门槛。

资本上半年猛投 AI，评论普遍提醒：多数智能体仍是通用辅助，垂直闭环、可量化回报和安全准入才是洗牌标准。约三到四成企业项目可能因回报不及预期停滞。

## 三、判断

1. Chat 正在变成工作入口：谁占据界面，谁绑定数据与权限。
2. Data Agent 进入“定义权”阶段，标准与落地案例比单点功能更重要。
3. 多智能体协作能力上升，失控与越权成本同步上升。
4. 国内机会在企业数据闭环，不在再做一个通用聊天机器人。

依据公开报道整理，不构成投资建议。
