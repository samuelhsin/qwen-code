## 二、数据智能体

Data Agent 从问数转向“受治理地连仓、出看板、可观测、可语音指挥”。OpenAI 9/10 在 Work 上线 Data agent，对接 Snowflake、BigQuery、Databricks、Redshift，写入 dbt / Horizon / Genie 语义层，可在 Tableau、Power BI 出看板并继承行列权限。Snowflake 把 Opus 5.5 公测放进 CoCo、CoWork、Cortex Agents，Astra 同期私测，调用不出治理边界；Observe 的 Agent Observability 即将私测。Databricks 称 Genie One MCP 已 GA。腾讯云 DataBuddy 以 Unity Semantics、Agent Runtime、OneOps 覆盖中泰韩印尼。Google Cloud 9/9 预览 Data Agent Kit。微软 Fabric 推 Agent Store。Teradata Tera 瞄准 Q4。

国内：快手 9/19 披露周活超 10600、周人均对话 55、单任务提效中位数 13 倍。云栖上阿里把 OpenLake 推向 Agentic Lake；DataWorks Context Graph 称业务问答准确率 93.24%、SQL 一致性 99%。IDC 中国 Data Agent 2026 四家进领导者，阿里云居首。

## 三、判断

1. 语音接到可执行 Work，但官方仍把独立语音锁在桌面；谁先打通插件与治理数据，谁占移动场景。
2. 任务单价决定路由，旗舰只留最难任务。
3. Data Agent 胜负手是语义层、MCP 与仓内治理，不是再做一个聊天框。
4. 峰会热线约束力弱于芯片、出口与投资审查。
5. 国内机会在企业数据闭环与云厂商全栈。
