# AI Chat 与大数据 Data Agent 产业简报

更新：2026-09-23 14:09 UTC（固定路径覆盖写入，不另存日期副本）

## 一、对话式 AI

本小时增量：法国主持的联合国安理会 AI 与国际安全会议于今日召开，OpenAI 的 Altman、Anthropic、DeepSeek、Moonshot 到场；专家组 9 月 21 日首份 Agent 简报已援引“预防原则”。产品侧，9 月 21–22 日 48 小时内中高端价位被重写：Grok 4.7 以每百万输入/输出 2/6 美元上线 Cursor 与 API；次日 Anthropic 推 Claude Opus 5.5（4/20 美元，缓存读取 0.20 美元），称多数工作达 Fable 5.1、较 Opus 5 典型负载约省 40%、输出快 30% 以上，Terminal-Bench 4.0 为 66.4%，并成为 Claude Code 与 App 默认模型；OpenAI 同日推 GPT-6 Sol（2/10）与 Luna（0.10/0.50），较 GPT-5.6 促销价腰斩且为长期价，上线 ChatGPT Work、Codex、API 与 Microsoft Foundry，Free/Go 可在桌面试用 Luna。Astra 仍接最难任务。OpenAI 9 月 10 日把 Agents API 放入公开测试，把长时程调度、沙箱与子代理做成托管接口。竞争单位已从旗舰跑分转到任务单价与缓存命中。

市场继续碎片化。Comscore Q2（9 月 22 日）显示 1–6 月提示量份额 ChatGPT 70%→50%、Gemini 17%→30%、Claude 2%→11%；移动端增速已超过桌面。Gemini 吃搜索/Android/Workspace，Claude 吃知识工作与编码。国内分层未破：豆包吃日常，DeepSeek 吃推理与低价 API，千问吃办公与长文档，Kimi 做长上下文与 Agent。独立 App 已定层，超级入口仍是分流变量。

## 二、数据智能体

Data Agent 从问数转向“受治理地连仓、出看板、可观测”。Databricks 称 Genie One MCP 已对全部用户 GA，经 Unity Gateway 把本体与权限交给外部智能体。Snowflake 9 月 22 日宣布 Observe 的 Agent Observability 即将私测，10 月 22 日办发布会；Cortex Agents 已进 Teams 与 M365 Copilot。Fabric data agent 可发 Copilot Agent Store，在 Teams 里按用户身份问 OneLake。OpenAI 9 月 10 日在 ChatGPT Work 上线 Data agent，对接主流数仓并写入语义层；Google Cloud 9 月 9 日预览 Data Agent Kit。

国内：快手 9 月 19 日沙龙披露 Data Agent 周活超 10600、周人均对话 55 次、单任务提效中位数 13 倍，分析与运营渗透超 80%。9 月 22 日云栖上，阿里云把 OpenLake 推向 Agentic Lake；DataWorks Context Graph 称业务问答准确率 93.24%、SQL 一致性 99%；ADA 做跨引擎多智能体编排。IDC《中国 Data Agent 2026》18 家入围、4 家进领导者，阿里云居首。语义层、权限与审计比单点 Text-to-SQL 更决定成交。

## 三、判断

1. 对话模型进入价效比阶段：谁把旗舰能力压到可规模化的任务单价，谁锁住 Agent 负载。
2. Chat 变成工作入口；界面绑定数据连接、语义层和权限。
3. Data Agent 胜负手是治理过的上下文加 MCP 分发与可观测，不是再做一个聊天框。
4. 国内机会在企业数据闭环与云厂商全栈，不在再做一个通用聊天机器人。
