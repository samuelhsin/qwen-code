## 大数据 Data Agent

IDC《MarketScape：中国 Data Agent 2026》18 家入选、仅 4 家领导者，阿里云居最前；预测 2028 年 60% 中国 500 强将部署企业级 Data Agent。DataWorks 覆盖开发、治理、分析、运维。数博会后北电数智发布面向 Agent 全场景的可信数据空间。Databricks 已让 Agent mode 覆盖全部 Genie Agents，可对 Unity Catalog 文件做多步分析，并把 3.8 Flash / Fable 5.1 收进托管；Genie One 联网搜索仍为 Beta。Microsoft Fabric Data Agent 可直接挂镜像库做 NL2SQL。Snowflake Horizon Context 把指标定义下沉数据层，Cortex Coding Agent 已 GA。Gartner 警告超 40% 的 Agent 项目或于 2027 年前失败。竞争从参数比拼转向语义层、网关与对结果负责。

## 判断

对话入口继续比更便宜的长程 Agent。本小时新事实：3.8 Flash 应用量再增约 12 亿 token，日窗口 Prompt 再抬约 63 亿，缓存把实付输入价压在标价约三成，Vertex 份额与命中微升，Flex 可用性继续修复但延迟再拉长。监管与诉讼无新增量。数据栈一边收新模型，一边让 Agent 对湖仓文件做多步取证。
