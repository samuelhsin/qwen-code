## 本小时增量

OpenRouter 上 Gemini 3.8 Flash 公开应用量本小时明显抬升：Hermes Agent 从 88.9 亿升至 98.3 亿 token，次席新上架 51.9 亿，pi 51.2 亿（上小时 49.3 亿、位列第二），Claude Code 13.9 亿升至 15.4 亿。Activity 仍报 Prompt 503 亿、Reasoning 5.47 亿、Completion 3.48 亿，说明累计口径未刷新，变化集中在应用榜与实付价。加权输入均价从 0.245 美元/百万再降至 0.2266 美元，输出均价 3.866 美元。Vertex 近一日流量 81.7%（上小时 81.6%），缓存命中 79.8%（上小时 77.2%）；Vertex Flex 可用性从 94.96% 回升至 96.53%，延迟仍约 13.7 秒，弱于 AI Studio 的 1.36 秒、99.79%。Hermes 全站累计约 49.4 万亿，日榜仍 1.59 万亿居首。本小时新纳入：OpenAI 回函国会称正在做自动关停能力；加州再增 30 起 Tumbler Ridge 相关诉讼。

## AI 对话

Google 9 月 2 日发 Gemini 3.8 Flash 与 3.8 Flash Cyber，六周内第三次 Flash，与 3.7 同价：输入 0.75 美元/百万、输出 3.75 美元，优惠至 2026-12-31。DeepSWE v1.1 73.7% 贴近 Opus 5 的 74.0%；Intelligence Index 58.7。Flash Cyber 仅经 Fairwind 给政府与关键基础设施。Anthropic 9 月 1 日发 Fable 5.1，缓存读价降 75% 至 0.25 美元/百万，长程 Agent 账单可降约 25%–45%；受限版 Mythos 5.1 面向网安与生命科学。OpenAI 9 月 1 日确认 Astra 达 Preparedness「Critical」网安门槛，高阶能力走 Daybreak Blue；9 月 3 日称正在开发自动关停，并收紧评测时联网。现役旗舰仍是 GPT-5.6。OpenRouter 截至 9 月 2 日周榜：GPT-5.6 Luna 11.6 万亿、GLM 5.3 Flash 与 DeepSeek V4 Flash 0731 各约 11.4 万亿。通义 Qwen3.8-Max（2.4 万亿 MoE）百炼 0902 快照强调长程编码与多智能体。欧盟 8 月 31 日将 ChatGPT 列为 DSA 超大型在线搜索引擎。

## 大数据 Data Agent

IDC《MarketScape：中国 Data Agent 2026》18 家入选、仅 4 家领导者，阿里云居最前；预测 2028 年 60% 中国 500 强将部署企业级 Data Agent。DataWorks 覆盖开发、治理、分析、运维。数博会后北电数智发布面向 Agent 全场景的可信数据空间，指出现有以人为中心的静态权限挡不住 Agent 跨库探索。Databricks 9 月 2 日让 AI Search 支持 struct/map 与仅过滤查询，Git Folder Serverless 进 Beta，并把 3.8 Flash / Fable 5.1 收进托管。Microsoft Fabric Data Agent 可直接挂镜像库做 NL2SQL。Snowflake Horizon Context 把指标定义下沉数据层。Gartner 警告超 40% 的 Agent 项目或于 2027 年前失败。竞争从参数比拼转向语义层、网关与对结果负责。

## 判断

对话入口继续比更便宜的长程 Agent。本小时新事实：3.8 Flash 应用量回升约 10 亿 token，缓存把实付输入价压到标价约三成，Vertex Flex 可用性略修复但延迟仍高一个数量级；监管与诉讼把「关停权」和内容安全推到台前。数据栈一边收新模型，一边补 Agent 取数的信任边界。
