## 二、数据智能体

赛迪顾问：中国 Data Agent 2025 年 16.8 亿元，2026 上半年 18.3 亿元，全年预计 40.2 亿元；分析智能体占 35%、治理 24%。IDC：到 2028 年 60% 中国 500 强将部署企业级 Data Agent。

湖仓争控制面。Databricks 11/16 指南把 Ontology（定义）与 Skills（方法）分开：技能用 Agent Skills 格式，经 Unity Gateway Skills（Beta）发布为 Unity Catalog 对象，可供 MCP Agent 复用。Genie Ontology/Search/Pages 已 GA；always-on 仍非 GA；ZeroOps Beta 11/12；Genie Slack 应用 GA。插件可进 ChatGPT、Claude、Copilot、Grok Bot。Gemini 3.6 Flash 11/19 自动改道 3.8 Flash。Snowflake 把 Ontology、AI Gateway、CoCo Automations 绑在权限与审计上。共性：没有语义层和权限继承的自然语言查仓不安全。

## 三、治理与判断

1. 含 App 时 ChatGPT 仍领先，纯 Web 上 Claude 十月跳得最快；商家 Agent 抢入口，成交仍回网站。
2. 数据 Agent 胜负手是 Ontology + Skills + 权限 + 审计 + 渠道；办公 Agent 升到会议/白板/表/群。
3. 窗口：Copilot 今日下线 Opus 4.8/5 与 GPT-5.6 Terra。Ignite 11/17–20。Claude Data 企业默认 11/20。Genie MCP Beta 与 Carbon 引入价叠在 11/30。欧盟 AI 法案 50(2) 过渡至 12/2。Copilot 12/14 再下 Fable 5、Gemini 3.8 Flash、Argon、Grok 4.6 等。语音 12/11 退役。
