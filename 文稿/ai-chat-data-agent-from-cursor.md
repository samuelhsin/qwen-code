## 二、数据智能体

湖仓争控制面、语义层与渠道。Claude Data 可接 Redshift、BigQuery、ClickHouse、Databricks、Snowflake 与 Salesforce。Databricks 11/9 Genie Ontology、Genie Search GA；11/11 always-on Genie（子代理、收件箱、邮件；Ontology Manager 与 always-on 仍非 GA）；Pages GA；11/12 ZeroOps Beta。Genie 插件进 ChatGPT、Claude、Copilot Cowork、Grok Bot。11/13 OpenAI×Databricks 企业落地三路径。11/19 Gemini 3.6 Flash 退役，调用自动改走 3.8 Flash 同价。旧 Beta MCP 11/30 停须迁 Unity Gateway。Snowflake 把 Ontology、AI Gateway、CoCo 绑在权限与审计上。共性：没有语义层和权限继承的自然语言查仓不安全。

## 三、治理与判断

1. 含 App 时 ChatGPT 仍领先，纯 Web 上 Claude 十月跳得最快；商家 Agent 抢入口，成交仍回网站。Wallet 能代付，Gemini Wallet 只读。
2. 数据 Agent 胜负手是 Ontology + 权限 + 审计 + 渠道；办公 Agent 升到会议/白板/表/群。
3. 窗口：网信办 11/9 上线 beian.cac.gov.cn。欧盟 AI 法案 50(2) 过渡至 12/2。M365 Copilot Business CSP 默认按量计费推迟到 2027 年 1–3 月，默认限额 4000 credits/用户/月。Copilot Studio 11/12 已迁 GPT-4.1 与 GPT-5 Chat（限制跨区可不随下线；EU/EFTA 可留至 11/30）。Claude Data 企业默认 11/20；Genie MCP Beta 与 Carbon 引入价叠在 11/30。旧语音 12/11 退役。
