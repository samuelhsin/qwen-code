## 三、治理与判断

1. 支付/短信/邮件/电话/CRM 写回都做成「先确认再执行」；湖仓侧数据不出域、代码封装、审计共享。Agent 分支试跑是新护栏。Agent 365 加 FinOps。集群限速从固定 QPS 改自适应并发。
2. 数据 Agent 胜负手是 Ontology + Skills + 权限 + 审计；办公 Agent 升到 Home/Cowork/岗位插件，并用路由争夺任务入口。
