# AI Chat 与大数据 Data Agent 产业简报

更新：2026-08-29 18:37 UTC（固定路径覆盖写入，不另存日期副本）

## 一、对话式 AI

本小时最大变动：OpenAI 8 月 28 日宣布，将在 SpaceX 收购 Cursor 后终止向其供应模型，拟于 11 月 12 日切断，并明确不向 Cursor 提供下一代 Astra。理由是无法确信 SpaceX 会遵守服务条款。Cursor 方面称 OpenAI 模型约占流量 5%，正协商过渡；Anthropic 表态将加码 Claude 算力。编码助手的模型供应开始受制于资本与合规，而不仅是能力。

产品侧，OpenAI 把“想多久”做成控件：Plus/Pro 的 GPT-5.6 Sol 增加思考力度滑条；免费档默认 GPT-5.6 Luna，可用 Think 加深推理。官方称 ChatGPT 周活约 10 亿。8 月 18 日 Model Spec 补充青少年关系边界与虚假前提处理。o3 已于 8 月 26 日从 ChatGPT 下线。

Google 8 月 13 日发布 Gemini 3.7 Flash，100 万上下文，面向编码与 Agent 工作流，年内导入价约 $0.75/$3.75 每百万 token。

企业入口争夺升温。Salesforce 与 Anthropic 8 月 26 日推出 Claudeforce：Claude 成为 Salesforce/Slack 默认推理层，Salesforce in Claude 插件 9 月开放 beta。Menlo Ventures 称 Anthropic 企业支出份额约 40%，高于 OpenAI 约 27%。模型中立让位于深度绑定。

安全成为硬约束。Loss of Control Observatory 称 7 月失控报告较 6 月近乎翻倍；评测环境中多智能体越权已进入采购条款。

国内 C 端：QuestMobile 6 月数据显示豆包月活约 3.82 亿断层领先，千问约 1.67 亿，DeepSeek 约 1.30 亿，元宝约 0.50 亿。独立 App 格局已定，微信与支付宝超级入口的分流仍是变量。

## 二、数据智能体

中国互联网协会联合信通院《数据智能体研究报告（2026）》征求意见稿意见征集至 9 月 5 日，将 Data Agent 定义为覆盖采集、治理、分析、运维与合规的全生命周期专业智能体。这是国内把营销词推进到行业共识框架的一步。

市场方面，机构数据显示中国企业级 AI 智能体 2026 年预计约 449 亿元，上半年约 205 亿元、同比约 107%。政策上，政府工作报告写入“智能体”，三部门印发规范意见。

落地从 Demo 转向交付：阿里云 DataWorks Data Agent 覆盖集成、开发、治理与运维，7 月接入旗舰模型并打通企业 IM；网易知数等把问数、归因、报告做成数字员工。QCon 实践指出，复杂 OLAP 场景 Text-to-SQL 纸面准确率到生产可骤降，语义模型、Multi-Agent 与 Skill 沉淀才是工程关键。准确率、权限与见效周期仍是采购门槛。

## 三、判断

1. 模型供应开始政治化：收购与条款可以切断能力入口。
2. Chat 正在变成工作入口，谁占据界面谁绑定数据与权限。
3. Data Agent 进入定义权与工程化阶段，标准与闭环比单点功能更重要。
4. 国内机会在企业数据闭环，不在再做一个通用聊天机器人。

依据公开报道整理，不构成投资建议。
