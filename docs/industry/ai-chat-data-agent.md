## Data Agent

Databricks 11/11 宣布二代 Always-on Genie：后台长跑、委派子智能体、收件箱/邮件把决策交回人；Genie Ontology 已 GA。Genie Search、Ontology Manager、always-on 仍为即将预览/测试，并非已全面 GA。动作受 Unity Catalog 与 Unity Gateway 约束。ChatGPT/Claude/Copilot/Grok 可通过插件或 MCP 取企业口径。11/13 与 OpenAI 给出三条路径：Genie 插件问数、Codex 走 Gateway、GPT 上 Model Serving。

Claude Data 已 GA（原 Dashboards），可连 Redshift/BigQuery 等；认证查询与直播分享仍测试。Team 默认开，Enterprise 11/20 默认开，管理员可在 Artifacts 改。

赛迪顾问：中国 Data Agent 2025 年 16.8 亿、2026H1 18.3 亿、全年预测 40.2 亿（按功能模块估算的 AI 增强增量，非独立赛道营收）。数据分析智能体约占 35%，数据治理增速最快约占 24%。

## 判断

对话入口正在变成交易与会议入口，审批与审计成为标配。Data Agent 竞争从「会问数」转向语义层、权限与花费上限。海外押钱包与常驻 Genie，国内拼办公入口与预览旗舰。11/20 Claude Data 默认、11/25 两家预览节点、12/14 Copilot 模型下线需提前准备。
