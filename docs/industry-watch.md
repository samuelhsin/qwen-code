# AI Chat 与 Data Agent 产业动态

更新时间：2026-11-05（UTC）。本文件为定时覆盖稿，只记录公开产业信号，不构成投资建议。

## AI Chat：对话入口继续变成能办事的助手

份额仍由 ChatGPT 主导，但增速已经分化。Sensor Tower 对 2026 年三季度的估计是：ChatGPT 月活约 14 亿、同比约增 70%；Gemini 约 5.91 亿、同比约增 166%；Claude 同比暴增约 1260%，份额仍只有约 4%。OpenAI 称 ChatGPT 的联网搜索量已相当于 Google 搜索量的约 20%，对话正在分流传统搜索。

产品竞争转向后台执行。Anthropic 开放 Claude Duet 候补名单：连接邮箱、账务和 CRM 后可先处理任务，再请用户确认。OpenAI 在 ChatGPT Work 和 Codex 上线 GPT-6.1 Terra，强调视觉推理和电脑操作，并宣布拟收购 Pierre，把代码浏览、差异审查和存储并入 Codex。Google 给 Gemini 增加小企业工作台，并把 Gemini 4 Carbon 先给网络安全伙伴。中国侧，阿里宣布千问接入 Apple Intelligence，计划进入 Siri、写作和视觉智能；相关趋势报告称 2026 年中中国 AI 推理数据量已超过训练数据量，产业重心从训模型转向用模型。

风险同步升温。有家长就 ChatGPT 相关医疗建议提起诉讼；Forum AI 称选举问答近四成存在事实错误；OpenAI 收紧青少年武器和攻击细节输出。对话产品正在补安全、可追溯和默认拒答。

## Data Agent：从能查数转向带语义、可治理、可闭环

咨询口径趋于一致。IDC 预测 2026 年半数中国 500 强将部署分析 Agent，2028 年六成部署企业级 Data Agent。爱分析把 Data+AI 拆成数据底座、开发运维、Agent 开发和行业应用四层，强调口径统一、从查询到行动、企业级可控。通用 Data Agent 竞争最充分，工业、金融、能源更吃行业知识和工具链。

云厂商本周动作集中在语义层。Google Cloud 更新 Agentic Data Cloud：跨云 Iceberg Lakehouse，受治理语义模型对接 BigQuery、Looker、Databricks、Snowflake、dbt 和 SAP。Snowflake 在 Expedition 2026 发布 Business Ontology 与 Cortex AI Gateway，CoCo Cloud Agents 可在既有权限内跑长任务和定时自动化。Databricks 以 Agent Bricks、Genie ontology、Unity AI Gateway 和 Lakebase 对位，强调多模型治理和支出上限。

落地瓶颈未变。企业愿为算力和数据付费，但对上层 Agent 是否单独买单尚未形成共识。最快场景仍是经营分析，不是营销。模型只是起点，缺口径、缺权限、缺可观测，Agent 只能停在演示层。

## 判断

对话产品在抢系统级入口和后台代理；数据平台在抢语义、权限和运行时。两边交汇点只有一句：Agent 能否按可信口径行动，并留下可审计、可回滚的痕迹。
